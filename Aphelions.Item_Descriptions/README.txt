This mod updates the weapon, tactical, and ordnance menu descriptions to have more information. This includes actual RPM firing rate, round sizes, and tidbits of lore for more of that military sci-fi immersion.

*** IMPORTANT: If you're using the Frontier Overhaul modpack, this mod already comes built-in! ***
Only place this in your addons if you DON'T have F.O. installed. If you try and use these two mods together, neither of them will work properly!

Good luck, have fun!
