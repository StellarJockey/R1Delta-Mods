This mod updates the weapon, tactical, and ordnance menu descriptions to have more information.

This includes:
-
* Actual RPM firing rate, round sizes, and tidbits of lore for more of that military sci-fi immersion.
* Unique icons for each weapon mod that previously used an already existing image (e.g. the R-97 scatterfire and the EVA-8 leadwall).
* A new, cleaner icon for the Charge Cannon.
* Higher resolution images for every Pilot and Titan weapon in the loadout previews.

**IMPORTANT:** If you're using the Frontier Overhaul modpack, this mod already comes built-in!
Only place this in your addons if you **DON'T** have F.O. installed. If you try and use these two mods together, **neither of them will work properly!**

Good luck, have fun!
