This is my repository for R1Delta mods.
To install, download this repo in bulk, extract the zip file, and simply place the desired mod folders into your addons folder in R1D.

---READ THIS BEFORE INSTALLING FRONTIER OVERHAUL---

* If you install the Frontier Overhaul mod, know that it comes built-in with FO-friendly versions of several other mods, including both the Instant Evac mod and the Item Descriptions mod. This is because, taken separately, those other mods will cause scripting conflicts and break the game.
* Frontier Overhaul's README has a full list of mods that it comes built-in with.
*  IF YOU ATTEMPT TO USE ANY OF THOSE MODS ALONGSIDE F.O., IT WILL BREAK THE GAME.

* The evac mod shown here is also -exclusively- meant for the owners of multiplayer servers.
* Other than that, Custom Backgrounds and Extra Music will work just fine alongside FO.

Good luck, have fun!
